Plugin Vibecodado com utilização do Opus 5 bem simples sobre roubo de vida que condiz com o título acima

Comandos:
/lifesteal give {player} {amount} - 
/lifesteal remove {player} {amount}

Mensagens configuráveis
Padrão de corações configuráveis
Quantidade máxima configurável

Sistema Anti-Dupe:
Item recebe valor único caso exista esse valor identico passar a ser inválido o item

Sistema Anti-Alt:
Jogadores que compartilham do mesmo IP não dropam corações e nem perdem

Versões em que o plugin suporta é dá 1.21+
